Projects in the cloud

All projects, with their locations, places, clients, "prepared by" and subcontractors, are kept on GitHub. Anyone who opens the calculator sees them, on any device. Photos and patente files are not sent online.

Saving from this device

Reading needs nothing. To save from this device, paste a GitHub key once:

  1. Open github.com/settings/tokens/new (signed in to GitHub).
  2. Set Expiration to No expiration, keep only public_repo ticked, click Generate token.
  3. Copy the key (starts with ghp_) and paste it here.

The key stays in this browser only. Anyone with the key can change the projects, so do not share it.
