# LED Screen Calculator

Web app of Unilumin Tunisia Africa Office for LED screen projects:

- **Sale**: flat screens, LED arch, mounting
- **Event**: rental screens, stage, control room, cameras, sound, lighting, translation, prints, several locations, subcontractors
- **Conception**: digital desk and digital fridge

`index.html` is the current version: one file, open it in any browser.
Earlier versions are in `versions/`, and the list of changes is in `CHANGELOG.md`.
