## What it covers

| Mode | Use it for |
|---|---|
| **Sale** | Flat LED screens, LED arch, mounting |
| **Event** | Rental screens, stage, control room, cameras, sound, lighting, live translation, prints, several locations, subcontractors |
| **Conception** | Digital desk and digital fridge |

### Sale

- Screen size, pitch and module data
- 3D view of the screen
- Receiving cards and ports, power supply layout, power and protection, power cable
- Control system
- Bill of materials
- LED arch with black cloth calculation and 360° views

### Event

- Event layout drawing: screens at the back of the stage, floor screens, printed visual under the screen (m²), lighting
- Screens and stock, main screen power
- Control room wiring
- Cameras and microphones (wired, wireless handheld, lavalier, headset, podium)
- Lighting: total number only, or detailed by type
- Live translation
- Subcontractors for LED screens, sound and lighting, with their names and phones
- Several locations in one project, with an "All locations" page
- Packing list and "What to bring"

### Conception

- **Digital desk**: desk shape, plan and views, LED faces, power supplies per face, connections and player, weight estimate, bill of materials, and a client PDF
- **Digital fridge**: left, front and right sides, LED faces, power supplies per face, power, weight, bill of materials

### Everywhere

- PDF export for the client
- Saved clients: typing a client name suggests clients already worked with and fills their phone and email
- Each project keeps its own locations and photos
- Light / dark interface
- Log of every version inside the app; each downloaded file is named with its version

## Files in this repository

| File | What it is |
|---|---|
| [`index.html`](index.html) | The current version, the page at the link above |
| [`versions/`](versions/) | Earlier versions, one file per version (`led-calculator_v74.html` … ) |
| [`CHANGELOG.md`](CHANGELOG.md) | List of changes for each version |

The whole app is one HTML file. To use it offline, download `index.html` and open it in a browser. PDF export needs an internet connection to load its library.

## Updates

New versions replace `index.html`, the previous version is kept in `versions/`, and the change is written in [`CHANGELOG.md`](CHANGELOG.md). The site updates a minute or two after each push.
